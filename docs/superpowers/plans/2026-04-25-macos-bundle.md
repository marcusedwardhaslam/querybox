# macOS Bundled Application Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a proper `.app` bundle and `.dmg` installer for QueryBox releases so users can double-click to open, see the app in Applications/Dock, and download a `.dmg` from GitHub Releases.

**Architecture:** `cargo-bundle` reads `[package.metadata.bundle]` from `Cargo.toml` and generates a `.app` with `Info.plist`. macOS-built-in `hdiutil` wraps the `.app` into a compressed `.dmg`. A placeholder `.icns` is generated once locally via a Python stdlib script and committed to the repo.

**Tech Stack:** Rust/Cargo, `cargo-bundle` (cargo install), `hdiutil` (macOS built-in), `iconutil` (macOS built-in), Python 3 stdlib (icon generation only)

### Task 1: Generate placeholder app icon

**Files:**
- Create: `dev/gen_icon.py`
- Create: `assets/icons/icon.icns` (generated by script, then committed)

- [ ] **Step 1: Create the icon generation script**

Create `dev/gen_icon.py` with this exact content:

```python
#!/usr/bin/env python3
"""Generate a placeholder .icns for QueryBox. Run from repo root: python3 dev/gen_icon.py"""

import os
import shutil
import struct
import subprocess
import zlib

R, G, B = 0x2B, 0x6C, 0xB0  # placeholder blue

def png_bytes(size):
    def chunk(tag, data):
        c = tag + data
        return struct.pack('>I', len(data)) + c + struct.pack('>I', zlib.crc32(c) & 0xFFFFFFFF)

    sig = b'\x89PNG\r\n\x1a\n'
    ihdr = chunk(b'IHDR', struct.pack('>IIBBBBB', size, size, 8, 2, 0, 0, 0))
    raw = b''.join(b'\x00' + bytes([R, G, B] * size) for _ in range(size))
    idat = chunk(b'IDAT', zlib.compress(raw))
    iend = chunk(b'IEND', b'')
    return sig + ihdr + idat + iend

SIZES = [
    ('icon_16x16.png',      16),
    ('icon_16x16@2x.png',   32),
    ('icon_32x32.png',      32),
    ('icon_32x32@2x.png',   64),
    ('icon_128x128.png',    128),
    ('icon_128x128@2x.png', 256),
    ('icon_256x256.png',    256),
    ('icon_256x256@2x.png', 512),
    ('icon_512x512.png',    512),
    ('icon_512x512@2x.png', 1024),
]

iconset = 'assets/icons/QueryBox.iconset'
os.makedirs(iconset, exist_ok=True)
os.makedirs('assets/icons', exist_ok=True)

for filename, size in SIZES:
    path = os.path.join(iconset, filename)
    with open(path, 'wb') as f:
        f.write(png_bytes(size))
    print(f'  wrote {path} ({size}x{size})')

subprocess.run(
    ['iconutil', '-c', 'icns', iconset, '-o', 'assets/icons/icon.icns'],
    check=True,
)
shutil.rmtree(iconset)
print('Done: assets/icons/icon.icns')
```

### Task 4: Update release workflow to produce DMG

**Files:**
- Modify: `.github/workflows/release.yml`

- [ ] **Step 1: Replace the build and publish steps**

The current `release.yml` has these steps (to be replaced):

```yaml
      - name: Build release binary
        run: cargo build --release --locked

      - name: Rename binary
        run: mv target/release/querybox ${{ matrix.artifact }}

      - name: Publish GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          files: ${{ matrix.artifact }}
          generate_release_notes: true
```

Replace them with:

```yaml
      - name: Install cargo-bundle
        run: cargo install cargo-bundle --locked

      - name: Build app bundle
        run: cargo bundle --release

      - name: Create DMG
        run: |
          hdiutil create \
            -volname QueryBox \
            -srcfolder "target/release/bundle/osx/QueryBox.app" \
            -ov \
            -format UDZO \
            ${{ matrix.artifact }}.dmg

      - name: Publish GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          files: ${{ matrix.artifact }}.dmg
          generate_release_notes: true
```
